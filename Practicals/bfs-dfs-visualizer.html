Breadth-First & Depth-First Search, Visually

Watch how a computer explores a tree, one tiny step at a time — and see exactly why a Queue and a Stack behave differently.

🚶 Queue FIFO — First In, First Out

Think of a canteen line. Whoever joins first, gets served first. BFS uses a Queue, so it explores the tree level by level.

🍽️ Stack LIFO — Last In, First Out

Think of a stack of plates. You can only take the top one off. DFS uses a Stack, so it dives deep down one path before backing up.
